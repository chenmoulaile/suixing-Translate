④ 网站规则

纯域名只比 hostname；含 * 按通配符；完整 URL 全等。

骨架按当前站点域名生成（pattern + 常用字段示例），粘贴进下方用户规则修改；导出下载内置规则与用户规则的完整 JSON。新字段 theme 可按站点固定译文主题（如 "theme": "paper"）。

保存前做 JSON 校验；内置规则 twitter/x.com、github.com、news.ycombinator.com 之后合并，同名字段用户规则整体覆盖，additional* 追加，selectors.add / selectors.remove 做增量。

⑤ 高级

最短字符数 最短词数

直属文本低于阈值的段落不收集（默认 4 字符 / 1 词）。

间隔阈值 ms

输入框内连续三次空格（相邻间隔均 ≤ 阈值，默认 200ms）把内容整段译成目标语言；替换后出现撤销浮条（点「撤销」还原，Ctrl+Z 也可）。斜杠命令：/ja 你好 后三连 → 仅命令后内容译为日语；//内容 → 仅命令后内容按默认目标语言翻译；替换前保留命令前缀原样。译文与原文相同时不替换并提示检查目标语言。可用快捷键 translate-input-box（Alt+I 可自行绑定，无默认键）直接翻译当前聚焦的输入框。

触发方式 修饰键 按住时长 ms

悬停候选段落先显示虚线轮廓；触发后译文内嵌在该段原文下方（与整页翻译同款排版）。修饰键按住再悬停已翻译段落 = 还原该段。「纯悬停」模式有 300ms 防扫过误触延迟。

样式 触发

气泡卡支持复制、朗读（本地 speechSynthesis）、重试与三档禁用（本次 / 本站 / 永久）。整句仅显示译文；单词查询可回显原文。输入框与代码块内选区不触发，避免与输入框翻译打架。

位置 不透明度 % 悬停展开延迟 ms

点击展开菜单（翻译本页 / 仅译文 / 主题选择 / 遮罩模式 / 导出双语 / 打开设置）；按住拖动可移动位置并记忆；全屏播放视频与打印时自动隐藏。首次使用前 5 次悬停会有「点击翻译本页」引导。

悬浮球「导出双语」菜单默认选中该格式；popup「更多」面板可三选一。导出按 DOM 顺序逐段「原文 + 译文」成对。

内置命令：toggle-translate（翻译/还原）、translate-full（整页翻译）、toggle-bilingual（双语/仅译文）、toggle-mask（遮罩学习全页开关，无默认键）、translate-input-box（翻译聚焦输入框，无默认键）。在 chrome://extensions/shortcuts（Edge：edge://extensions/shortcuts）查看与修改绑定。

⑦ AI 与扩展场景

本节功能依赖相应服务与内容脚本模块；AI 能力需要配置 AI 服务密钥（或本地 Ollama）后才会真正生效。

AI 术语库与智能上下文

翻译时附带术语表，确保同一术语全文译法一致。仅对 AI 服务生效（Claude / Gemini / DeepSeek / Ollama / OpenAI）；对谷歌、微软等免 key 服务无效。

内置法律 / 医疗 / 电商 / 教育 / 游戏 / 小说 / 金融 / 科技等词库，由 background/terminology.js 提供；可与自定义术语叠加。

与预设词库合并；仅对 AI 服务生效。

翻译时附带前后段落作为上下文，提升连贯度；会增加 token 消耗与请求体积，仅在 AI 服务下生效。

译文布局

「并排双语」对新翻译的段落生效；已翻译的页面需先还原再重新翻译才会按新布局渲染。

双语字幕

在 YouTube / 带 WebVTT 字幕的网页上叠加双语字幕；开启后需刷新视频页才会挂载，也可通过 popup「双语字幕开关」或悬浮球即时切换。

字号 px 目标语言

自动双语：原文与译文同屏显示；关闭则仅显示译文。字幕目标语言留空时跟随「① 基础」的目标语言。

AI 词典卡

划词查询单词时由 AI 生成释义 / 音标 / 例句卡片；需配置 AI 服务密钥（或本地 Ollama）后生效。

图片翻译

对页面图片做 OCR 识别后翻译，依赖 OCR 服务；免费 OCR key 通常有调用频率限制。

文档翻译

在独立页面翻译 PDF / EPUB / TXT / SRT / Markdown / HTML 文档（PDF 解析由内置 pdf.js 完成）。也可从 popup「更多」或悬浮球菜单进入。

⑧ 关于

安装（Chrome ≥102）

  1. 打开 chrome://extensions/；
  2. 右上角打开「开发者模式」；
  3. 点击「加载已解压的扩展程序」；
  4. 选择目录 D:\code\translate-anywhere。

安装（Edge ≥102）

  1. 打开 edge://extensions/；
  2. 左侧打开「开发人员模式」；
  3. 点击「加载解压缩的扩展」；
  4. 选择同一目录（零改动）。

隐私声明

待翻译文本仅发送到你选择的翻译服务商（浏览器直连）；API key 等配置仅保存在本地 chrome.storage.local，不回传任何第三方；扩展不收集浏览历史与个人信息。

免责声明

内置免费接口（谷歌 / DeepL 免费 / 微软 / 彩云 / 有道 / 讯飞）为非官方公开端点，可能随时失效或被风控，届时扩展自动沿降级链回退；如需稳定服务请自行申请官方 API 并配置密钥。本扩展仅供学习研究使用，使用风险自负。

⑨ 设置页翻译

看不懂界面文字？可把本设置页的标签与说明文字直接译成下方所选语言，方便阅读；输入项与按钮文字保持不动，译文以淡色标注显示在原文之后，随时可一键还原。

翻译通过本扩展自身的翻译服务完成，需要至少有一个可用服务（谷歌 / 微软等免密钥服务默认可用，AI 服务需配置密钥）；某项失败时已完成的翻译会保留。
